# AI agent package

Read README.md and Ecaty's canonical [PROJECT](https://github.com/Ecaty/Ecaty/blob/main/docs/PROJECT.md), [DEVELOPMENT](https://github.com/Ecaty/Ecaty/blob/main/docs/DEVELOPMENT.md), [AI-INTEGRATION](https://github.com/Ecaty/Ecaty/blob/main/docs/AI-INTEGRATION.md) and [STATUS](https://github.com/Ecaty/Ecaty/blob/main/docs/STATUS.md). In the composed checkout they are at `../../docs/`.

Keep the UI, conversation/tool orchestration and provider adapters reusable across Unity apps. Use namespace `Ecaty.Agents`. Never depend on Flecs or a product's native library; accept generic instructions and tool callbacks from the host. Keep provider-specific protocols/authentication in adapters and outside the shared view. Do not imply universal subscription/account access; verify the selected provider's supported flow. Keep tokens, accounts, messages and recordings out of source/assets and logs. UI remains messages, input/send and optional dictation. Do not simulate a live provider with fake runtime replies. Marshal Unity/world tool work to the owning thread. Preserve .meta GUIDs and verify imports/events using the package check. Actual provider connections require separate end-to-end verification.
